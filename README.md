# 🏥 TrustHomeCare – Medical Equipment & Appointment Booking System

## 🚀 Project Overview  
TrustHomeCare is a full-stack MERN application that allows users to book medical services and rent healthcare equipment online.  
It simplifies appointment scheduling and equipment booking with an integrated email notification system.

This project was built to practice and strengthen real-world full stack development concepts.

---

## ✨ Features  

- Appointment Booking System  
  - Book medical consultations (e.g., General Physician)  
  - Select preferred date and time  

- Medical Equipment Rental  
  - Rent equipment like electric wheelchairs  
  - Provide delivery address and additional notes  

- Email Notification System 📧  
  - Confirmation email sent to the user  
  - Booking details sent to the admin/owner  
  - Dynamic email templates with booking information  

- Responsive User Interface  
  - Clean and simple design  
  - Works across different screen sizes  

- Full Stack Implementation  
  - Complete integration of frontend, backend, and database

## ⚙️ Installation & Setup  

```bash
# Clone the repository
git clone https://github.com/Satya7727/TrustHomeCare.git

# Navigate into the project
cd TrustHomeCare

# Install backend dependencies
cd backend
npm install

# Start backend server
npm start

# Install frontend dependencies
cd ../frontend
npm install

# Start frontend
npm run dev
